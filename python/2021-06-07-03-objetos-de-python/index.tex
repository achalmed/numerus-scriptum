\section{Listas}\label{listas}

Las listas son objetos mutables e iterables en python. Son muy
versátiles pues permiten coleccionar de manera ordenada cualquier objeto
(incluso otras listas). Las listas además te permiten acceder a los
elementos que contiene adentro utilizando índices.

\BuiltInTok{print}\NormalTok{(frutas)}
\end{Highlighting}
\end{Shaded}

\begin{Shaded}
\begin{Highlighting}[]

\section{Asignación como referencia o como
valor}\label{asignaciuxf3n-como-referencia-o-como-valor}

Muchos cometen el error de `copiar' una lista de manera directa y luego
editarla. El resultado es que todas las ediciones que hagamos en la
lista referida se replicaran en la lista original. Esto ocurre cuando
asignamos una lista como referencia en lugar de copiarla.

Cuando la asignamos como referencia lo unico que hace python es usar el
nuevo nombre de variable para referenciar la variable original. Esto
permite a python salvar memoria ram porque no estamos creando más
objetos en el ambiente de python.

\begin{Shaded}
\begin{Highlighting}[]
\ImportTok{import}\NormalTok{ copy}

\NormalTok{miPrimeraLista }\OperatorTok{=}\NormalTok{ [}\DecValTok{1}\NormalTok{, }\DecValTok{2}\NormalTok{, }\DecValTok{3}\NormalTok{, }\DecValTok{4}\NormalTok{, }\DecValTok{5}\NormalTok{]}
\NormalTok{miPrimeraLista1 }\OperatorTok{=}\NormalTok{ miPrimeraLista }\CommentTok{\# Esto asigna como referencia}
\NormalTok{miPrimeraLista2 }\OperatorTok{=}\NormalTok{ copy.copy(miPrimeraLista) }\CommentTok{\# Esto asigna como valor}
\CommentTok{\#miPrimeraLista[0]}
\NormalTok{miPrimeraLista[}\DecValTok{0}\NormalTok{] }\OperatorTok{=} \DecValTok{3}
\NormalTok{miPrimeraLista[}\DecValTok{1}\NormalTok{] }\OperatorTok{=} \DecValTok{9}

\BuiltInTok{print}\NormalTok{(}\StringTok{\textquotesingle{}miPrimeraLista :\textquotesingle{}}\NormalTok{,miPrimeraLista)}
\BuiltInTok{print}\NormalTok{(}\StringTok{\textquotesingle{}miPrimeraLista1:\textquotesingle{}}\NormalTok{,miPrimeraLista1)}
\BuiltInTok{print}\NormalTok{(}\StringTok{\textquotesingle{}miPrimeraLista2:\textquotesingle{}}\NormalTok{,miPrimeraLista2)}
\end{Highlighting}
\end{Shaded}

En el caso de listas de listas la función que nos permite copiar el
objeto completo es la rutina deepcopy. Basicamente lo que hace deepcopy
es copiar como valor no solo la lista inicial, sino tambien las listas
que se contienen adentro.

\begin{Shaded}
\begin{Highlighting}[]
\CommentTok{\#List of lists:}
\NormalTok{miSegundaLista }\OperatorTok{=}\NormalTok{ [[}\StringTok{"Jose"}\NormalTok{, }\StringTok{"Pablo"}\NormalTok{], [}\DecValTok{26}\NormalTok{, }\DecValTok{25}\NormalTok{]]}
\NormalTok{miSegundaListaNombres }\OperatorTok{=}\NormalTok{ miSegundaLista }\CommentTok{\# Esto asigna como referencia}
\NormalTok{miSegundaListaNombres2 }\OperatorTok{=}\NormalTok{ copy.deepcopy(miSegundaLista) }\CommentTok{\# Deepcopy asigna como valor las listas y sublistas}
\NormalTok{miSegundaLista[}\DecValTok{1}\NormalTok{][}\DecValTok{1}\NormalTok{] }\OperatorTok{=} \DecValTok{24}
\BuiltInTok{print}\NormalTok{(}\StringTok{\textquotesingle{}Lista original:\textquotesingle{}}\NormalTok{,miSegundaLista)}
\BuiltInTok{print}\NormalTok{(}\StringTok{\textquotesingle{}Lista copiada como referencia:\textquotesingle{}}\NormalTok{,miSegundaListaNombres)}
\BuiltInTok{print}\NormalTok{(}\StringTok{\textquotesingle{}Lista copiada como valor:\textquotesingle{}}\NormalTok{,miSegundaListaNombres2)}
\end{Highlighting}
\end{Shaded}

\section{Evaluando la existencia de objetos en una
lista}\label{evaluando-la-existencia-de-objetos-en-una-lista}

En python es posible evaluar la membresía de un elemento en colecciones
de elementos como listas, sets, diccionarios y tuplas. Para ello existen
los comandos ``in'', ``not in''.

Así mismo es posible evaluar si un objeto en python es identico a otro.
Esta rutina evalúa si un objeto tiene el mismo valor y propiedades que
otro, para ello se usa la rutina ``is''.

\begin{Shaded}
\begin{Highlighting}[]

\BuiltInTok{print}\NormalTok{(}\DecValTok{5} \KeywordTok{not} \KeywordTok{in}\NormalTok{ mylist)}

\section{Trabajando con tuplas.}\label{trabajando-con-tuplas.}

\section{Diccionarios:}\label{diccionarios}

Los diccionarios son colecciones de elementos de manera no ordenada, son
mutables y posibles de indexar. En python la forma de crear diccionarios
es usando llaves ``\{\}''. Los diccionarios se utilizan para elaborar
estructuras de datos que contienen multiples objetos y usualmente se
pueden referenciar on un ``key name'' que suele ser un string. Por lo
general los diccionarios siguen la siguiente estructura:

\begin{verbatim}
                                   dictorinary = { 'key1': obj1,
                                                   'key2': obj2,
                                                   'key3': obj3}
\end{verbatim}

\BuiltInTok{print}\NormalTok{(miDict[}\StringTok{\textquotesingle{}a\textquotesingle{}}\NormalTok{])}
\end{Highlighting}
