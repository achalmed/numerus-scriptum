\section{¿Por qué es importante aprender un lenguaje de
programación?}\label{por-quuxe9-es-importante-aprender-un-lenguaje-de-programaciuxf3n}

\subsection{La transformación digital de la
economía}\label{la-transformaciuxf3n-digital-de-la-economuxeda}

En las últimas décadas, la economía ha experimentado una revolución
digital sin precedentes. Como economistas, nos enfrentamos diariamente
a:

\begin{itemize}
\tightlist
\item
  \textbf{Grandes volúmenes de datos}: Series temporales
  macroeconómicas, microdatos de encuestas de hogares, datos de
  transacciones financieras, registros administrativos, entre otros.
\item
  \textbf{Análisis cada vez más complejos}: Modelos econométricos
  avanzados, análisis de impacto, predicciones económicas, evaluación de
  políticas públicas.
\item
  \textbf{Necesidad de reproducibilidad}: La investigación económica
  moderna exige que nuestros análisis sean replicables y transparentes.
\end{itemize}

\subsection{Ventajas de programar como
economista}\label{ventajas-de-programar-como-economista}

\textbf{Automatización de tareas repetitivas}

Imagina que necesitas calcular el índice de Gini para los 25
departamentos del Perú utilizando la Encuesta Nacional de Hogares
(ENAHO). Sin programación, esto implicaría:

\begin{itemize}
\tightlist
\item
  Abrir cada archivo de datos manualmente
\item
  Realizar cálculos en Excel repetidamente
\item
  Alto riesgo de errores humanos
\item
  Horas o días de trabajo
\end{itemize}

Con programación, este proceso se reduce a minutos y es 100\%
reproducible.

\textbf{Análisis de datos más sofisticados}

La programación te permite:

\begin{itemize}
\tightlist
\item
  Implementar modelos econométricos avanzados (VAR, GARCH, modelos de
  panel dinámico)
\item
  Realizar simulaciones de Monte Carlo para análisis de riesgo
\item
  Aplicar técnicas de machine learning para predicción económica
\item
  Crear visualizaciones interactivas de datos económicos
\end{itemize}

\textbf{Ventaja competitiva en el mercado laboral}

Las instituciones que más demandan economistas hoy en día buscan
profesionales con habilidades de programación:

\begin{itemize}
\tightlist
\item
  Banco Central de Reserva del Perú (BCRP)
\item
  Ministerio de Economía y Finanzas (MEF)
\item
  Instituciones financieras privadas
\item
  Consultorias económicas
\item
  Organismos internacionales (BID, Banco Mundial, FMI)
\end{itemize}

\section{Curva de aprendizaje y alcance de distintos

\subsection{Comparación de lenguajes para análisis

\subsubsection{\texorpdfstring{\textbf{Stata}}{Stata}}\label{stata}

\textbf{Ventajas:}

\begin{itemize}
\tightlist
\item
  Diseñado específicamente para econometría
\item
  Sintaxis intuitiva para economistas
\item
  Excelente documentación de métodos econométricos
\item
  Ampliamente usado en investigación académica
\end{itemize}

\textbf{Desventajas:}

\begin{itemize}
\tightlist
\item
  Licencia costosa (aproximadamente \$1,200 USD para estudiantes)
\item
  Limitado para tareas fuera de econometría tradicional
\item
  Menos flexible para automatización compleja
\item
  Comunidad más pequeña que Python o R
\end{itemize}

\textbf{Curva de aprendizaje:} Baja-Media (2-3 meses para dominar lo
básico)

\textbf{Ejemplo en Stata:}

\begin{Shaded}

\subsubsection{\texorpdfstring{\textbf{R}}{R}}\label{r}

\textbf{Ventajas:}

\begin{itemize}
\tightlist
\item
  Gratuito y de código abierto
\item
  Excelente para estadística y visualización de datos
\item
  Gran cantidad de paquetes econométricos (plm, AER, forecast)
\item
  RStudio como entorno amigable
\end{itemize}

\textbf{Desventajas:}

\begin{itemize}
\tightlist
\item
  Sintaxis puede ser inconsistente entre paquetes
\item
  Menor rendimiento con grandes volúmenes de datos
\item
  Menos usado fuera del ámbito académico/estadístico
\end{itemize}

\textbf{Curva de aprendizaje:} Media (3-4 meses para dominar lo básico)

\section{¿Qué es Data Science? ¿Qué es Machine
Learning?}\label{quuxe9-es-data-science-quuxe9-es-machine-learning}

\subsection{Data Science (Ciencia de
Datos)}\label{data-science-ciencia-de-datos}

\textbf{Definición:}

Data Science es un campo interdisciplinario que utiliza métodos
científicos, procesos, algoritmos y sistemas para extraer conocimiento e
insights de datos estructurados y no estructurados.

\textbf{En términos económicos:}

Data Science es el conjunto de técnicas y herramientas que nos permiten:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Recolectar} datos económicos de múltiples fuentes
\item
  \textbf{Limpiar y procesar} datos (a menudo el 80\% del trabajo)
\item
  \textbf{Analizar} patrones y relaciones
\item
  \textbf{Visualizar} resultados de forma comprensible
\item
  \textbf{Comunicar} hallazgos para la toma de decisiones
\end{enumerate}

\textbf{Componentes del Data Science:}

\begin{verbatim}
Data Science = Matemáticas + Estadística + Programación + Conocimiento del dominio
\end{verbatim}

Para economistas:

\begin{itemize}
\tightlist
\item
  \textbf{Matemáticas}: Cálculo, álgebra lineal, optimización
\item
  \textbf{Estadística}: Inferencia, pruebas de hipótesis, econometría
\item
  \textbf{Programación}: Python, SQL, manejo de datos
\item
  \textbf{Conocimiento del dominio}: Teoría económica, instituciones,
  contexto
\end{itemize}

\subsection{Machine Learning (Aprendizaje
Automático)}\label{machine-learning-aprendizaje-automuxe1tico}

\textbf{Definición:}

Machine Learning es un subcampo de la inteligencia artificial que
permite a las computadoras aprender patrones de los datos sin ser
programadas explícitamente.

\textbf{Diferencia con econometría tradicional:}

\textbf{Econometría tradicional:}

\begin{itemize}
\tightlist
\item
  Enfoque: Inferencia causal y prueba de teorías
\item
  Objetivo: Entender \textbf{por qué} sucede algo
\item
  Ejemplo: ¿Cuál es el efecto causal de la educación sobre los ingresos?
\item
  Prioridad: Interpretabilidad y validez causal
\end{itemize}

\textbf{Machine Learning:}

\begin{itemize}
\tightlist
\item
  Enfoque: Predicción y reconocimiento de patrones
\item
  Objetivo: Predecir \textbf{qué} va a suceder
\item
  Ejemplo: ¿Cuál será el ingreso de una persona dado su perfil?
\item
  Prioridad: Precisión predictiva
\end{itemize}

\subsection{Tipos de Machine Learning}\label{tipos-de-machine-learning}

\subsubsection{Aprendizaje Supervisado (Supervised
Learning)}\label{aprendizaje-supervisado-supervised-learning}

Aprendemos de datos etiquetados (conocemos la respuesta correcta).

\textbf{Ejemplos:}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\item
  \textbf{Clasificación}: Predecir si una empresa caerá en default
  (sí/no)

  \begin{itemize}
  \tightlist
  \item
    Variable objetivo: Binaria (default o no default)
  \item
    Algoritmos: Regresión logística, árboles de decisión, random forests
  \end{itemize}
\item
  \textbf{Regresión}: Predecir el precio de una vivienda

  \begin{itemize}
  \tightlist
  \item
    Variable objetivo: Continua (precio en soles)
  \item
    Algoritmos: Regresión lineal, regresión ridge, redes neuronales
  \end{itemize}
\end{enumerate}

\subsubsection{Aprendizaje No Supervisado (Unsupervised
Learning)}\label{aprendizaje-no-supervisado-unsupervised-learning}

Encontramos patrones en datos sin etiquetas.

\textbf{Ejemplos:}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\item
  \textbf{Clustering}: Segmentar consumidores en grupos similares

  \begin{itemize}
  \tightlist
  \item
    Identificar perfiles de ahorradores
  \item
    Agrupar países por nivel de desarrollo
  \end{itemize}
\item
  \textbf{Reducción de dimensionalidad}: Simplificar datos con muchas
  variables

  \begin{itemize}
  \tightlist
  \item
    Análisis de componentes principales (PCA)
  \item
    Crear índices sintéticos
  \end{itemize}
\end{enumerate}

\subsection{Aplicaciones de Machine Learning en
economía}\label{aplicaciones-de-machine-learning-en-economuxeda}

\subsubsection{Caso 1: Predicción de morosidad
bancaria}\label{caso-1-predicciuxf3n-de-morosidad-bancaria}

Un banco necesita predecir qué clientes tienen mayor probabilidad de no
pagar su préstamo.

\textbf{Enfoque tradicional (Regresión logística):}

\begin{verbatim}
P(default) = f(ingresos, historial_crediticio, edad, educación)
\end{verbatim}

\textbf{Enfoque ML (Random Forest):}

\begin{itemize}
\tightlist
\item
  Considera interacciones complejas entre variables
\item
  Puede capturar relaciones no lineales
\item
  Mayor precisión predictiva (pero menos interpretable)
\end{itemize}

\subsubsection{Caso 2: Detección de fraude
fiscal}\label{caso-2-detecciuxf3n-de-fraude-fiscal}

SUNAT quiere identificar empresas con alta probabilidad de evasión
tributaria.

\textbf{Variables:}

\begin{itemize}
\tightlist
\item
  Ingresos declarados vs.~estimados por sector
\item
  Patrones inusuales en deducciones
\item
  Relaciones con proveedores
\item
  Historial de fiscalizaciones
\end{itemize}

\textbf{Algoritmo:} Anomaly detection o clasificación supervisada

\subsubsection{Caso 3: Predicción del tipo de
cambio}\label{caso-3-predicciuxf3n-del-tipo-de-cambio}

\textbf{Modelos tradicionales:}

\begin{itemize}
\tightlist
\item
  ARIMA: Serie temporal univariada
\item
  VAR: Múltiples series, relaciones lineales
\end{itemize}

\textbf{Modelos ML:}

\begin{itemize}
\tightlist
\item
  Redes neuronales LSTM: Capturan patrones temporales complejos
\item
  Ensemble methods: Combinan múltiples modelos para mejor predicción
\end{itemize}
