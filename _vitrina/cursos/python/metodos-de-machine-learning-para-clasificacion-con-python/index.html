2 Regresión logística

2.1 Fundamento matemático

La regresión logística es uno de los métodos más fundamentales y ampliamente utilizados para problemas de clasificación binaria. A pesar de su nombre que incluye “regresión”, es un algoritmo de clasificación que predice probabilidades de pertenencia a clases mediante una transformación no lineal de una combinación lineal de características.

2.1.1 Modelo de probabilidad

Para clasificación binaria donde Y∈{0,1}Y \in \{0, 1\}Y∈{0,1}, la regresión logística modela la probabilidad de que la observación pertenezca a la clase positiva (Y=1Y=1Y=1):

P(Y=1∣X)=p(X)=11+e−(β0+β1X1+⋯+βpXp) P(Y=1 | \mathbf{X}) = p(\mathbf{X}) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 X_1 + \cdots + \beta_p X_p)}} P(Y=1∣X)=p(X)=1+e−(β0​+β1​X1​+⋯+βp​Xp​)1​

Definiendo la combinación lineal: z=β0+β1X1+β2X2+⋯+βpXp=β0+X⊤β z = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \cdots + \beta_p X_p = \beta_0 + \mathbf{X}^\top\boldsymbol{\beta} z=β0​+β1​X1​+β2​X2​+⋯+βp​Xp​=β0​+X⊤β

La probabilidad se expresa como: p(X)=11+e−z=ez1+ez p(\mathbf{X}) = \frac{1}{1 + e^{-z}} = \frac{e^z}{1 + e^z} p(X)=1+e−z1​=1+ezez​

Esta función se conoce como función logística o sigmoide.

2.1.2 Función sigmoide

La función sigmoide tiene la forma: σ(z)=11+e−z \sigma(z) = \frac{1}{1 + e^{-z}} σ(z)=1+e−z1​

Propiedades clave:

  1. Rango: σ(z)∈(0,1)\sigma(z) \in (0, 1)σ(z)∈(0,1) para todo z∈Rz \in \mathbb{R}z∈R

    • Garantiza que las predicciones sean probabilidades válidas

  2. Simetría: σ(−z)=1−σ(z)\sigma(-z) = 1 - \sigma(z)σ(−z)=1−σ(z)

  3. Límites asintóticos: lim⁡z→∞σ(z)=1,lim⁡z→−∞σ(z)=0 \lim_{z \to \infty} \sigma(z) = 1, \quad \lim_{z \to -\infty} \sigma(z) = 0 z→∞lim​σ(z)=1,z→−∞lim​σ(z)=0

  4. Punto medio: σ(0)=0.5\sigma(0) = 0.5σ(0)=0.5

  5. Derivada: dσ(z)dz=σ(z)(1−σ(z)) \frac{d\sigma(z)}{dz} = \sigma(z)(1 - \sigma(z)) dzdσ(z)​=σ(z)(1−σ(z)) Esta propiedad simplifica el cálculo de gradientes.

2.1.3 Odds y log-odds (logit)

Odds (momios):

La probabilidad de éxito sobre la probabilidad de fracaso: Odds=p(X)1−p(X)=ez \text{Odds} = \frac{p(\mathbf{X})}{1 - p(\mathbf{X})} = e^z Odds=1−p(X)p(X)​=ez

Log-odds (logit):

Tomando logaritmo natural: log⁡(p(X)1−p(X))=z=β0+β1X1+⋯+βpXp \log\left(\frac{p(\mathbf{X})}{1-p(\mathbf{X})}\right) = z = \beta_0 + \beta_1 X_1 + \cdots + \beta_p X_p log(1−p(X)p(X)​)=z=β0​+β1​X1​+⋯+βp​Xp​

Esta es la transformación logit que convierte probabilidades (0,1) al rango completo de números reales (−∞,∞)(-\infty, \infty)(−∞,∞).

Interpretación crucial: El modelo es lineal en el log-odds, no en la probabilidad misma.

2.1.4 Interpretación de coeficientes

Un incremento unitario en XjX_jXj​ (manteniendo otras variables constantes):

En log-odds: Δlog⁡(Odds)=βj \Delta \log(\text{Odds}) = \beta_j Δlog(Odds)=βj​

En odds: Odds ratio=eβj \text{Odds ratio} = e^{\beta_j} Odds ratio=eβj​

  • Si βj>0\beta_j > 0βj​>0: eβj>1e^{\beta_j} > 1eβj​>1 → La variable incrementa el odds de Y=1Y=1Y=1
  • Si βj<0\beta_j < 0βj​<0: eβj<1e^{\beta_j} < 1eβj​<1 → La variable reduce el odds de Y=1Y=1Y=1
  • Si βj=0\beta_j = 0βj​=0: eβj=1e^{\beta_j} = 1eβj​=1 → La variable no afecta el odds

Efecto marginal en probabilidad: ∂p∂Xj=βj⋅p(X)⋅(1−p(X)) \frac{\partial p}{\partial X_j} = \beta_j \cdot p(\mathbf{X}) \cdot (1 - p(\mathbf{X})) ∂Xj​∂p​=βj​⋅p(X)⋅(1−p(X))

El efecto no es constante; depende del nivel de probabilidad actual.

2.1.5 Estimación: Maximum Likelihood

Los coeficientes se estiman mediante máxima verosimilitud (MLE).

Log-verosimilitud: ℓ(β)=∑i=1n[Yilog⁡p(Xi)+(1−Yi)log⁡(1−p(Xi))] \ell(\boldsymbol{\beta}) = \sum_{i=1}^{n} \left[ Y_i \log p(\mathbf{X}_i) + (1-Y_i) \log(1-p(\mathbf{X}_i)) \right] ℓ(β)=i=1∑n​[Yi​logp(Xi​)+(1−Yi​)log(1−p(Xi​))]

Objetivo: Maximizar ℓ(β)\ell(\boldsymbol{\beta})ℓ(β) mediante métodos iterativos (Newton-Raphson, gradient descent).

Función de pérdida equivalente (Binary Cross-Entropy): BCE(β)=−1n∑i=1n[Yilog⁡p^i+(1−Yi)log⁡(1−p^i)] \text{BCE}(\boldsymbol{\beta}) = -\frac{1}{n}\sum_{i=1}^{n} \left[ Y_i \log \hat{p}_i + (1-Y_i) \log(1-\hat{p}_i) \right] BCE(β)=−n1​i=1∑n​[Yi​logp^​i​+(1−Yi​)log(1−p^​i​)]

2.1.6 Frontera de decisión

La frontera de decisión es donde p(X)=0.5p(\mathbf{X}) = 0.5p(X)=0.5: β0+β1X1+⋯+βpXp=0 \beta_0 + \beta_1 X_1 + \cdots + \beta_p X_p = 0 β0​+β1​X1​+⋯+βp​Xp​=0

En el espacio de características, esta es una hipersuperficie lineal (hiperplano).

2.1.7 Ventajas

  • Salidas probabilísticas interpretables
  • Eficiencia computacional
  • Pocos hiperparámetros
  • Funciona bien como baseline
  • Extensible a clasificación multi-clase

2.1.8 Limitaciones

  • Asume linealidad en log-odds
  • No captura relaciones no lineales complejas
  • Sensible a outliers
  • Requiere features relevantes

2.1.9 Aplicaciones económicas

  • Predicción de incumplimiento crediticio
  • Participación laboral
  • Decisiones de compra
  • Migración
  • Adopción de tecnología
  • Éxito de startups

3 K-Nearest Neighbors (KNN)

3.1 Fundamento del algoritmo

K-Nearest Neighbors es un algoritmo de clasificación no paramétrico basado en la premisa de que observaciones similares (vecinas) tienden a pertenecer a la misma clase. Es uno de los algoritmos más simples conceptualmente, pero sorprendentemente efectivo en muchas aplicaciones.

3.1.1 Principio fundamental

Idea central: “Dime quiénes son tus vecinos y te diré quién eres”

Una nueva observación se clasifica según la clase más común entre sus kkk vecinos más cercanos en el espacio de características.

3.1.2 Definición formal

Dado:

  • Conjunto de entrenamiento D={(Xi,Yi)}i=1n\mathcal{D} = \{(\mathbf{X}_i, Y_i)\}_{i=1}^{n}D={(Xi​,Yi​)}i=1n​
  • Nuevo punto a clasificar X0\mathbf{X}_0X0​
  • Número de vecinos kkk

El algoritmo:

  1. Calcular distancias a todos los puntos de entrenamiento: di=d(X0,Xi)para i=1,…,n d_i = d(\mathbf{X}_0, \mathbf{X}_i) \quad \text{para } i = 1, \ldots, n di​=d(X0​,Xi​)para i=1,…,n

  2. Identificar los kkk puntos con menores distancias: Nk(X0)={k vecinos maˊs cercanos} \mathcal{N}_k(\mathbf{X}_0) = \{k \text{ vecinos más cercanos}\} Nk​(X0​)={k vecinos maˊs cercanos}

  3. Votar por mayoría: Y^0=arg⁡max⁡c∑i∈Nk(X0)1(Yi=c) \hat{Y}_0 = \arg\max_{c} \sum_{i \in \mathcal{N}_k(\mathbf{X}_0)} \mathbb{1}(Y_i = c) Y^0​=argcmax​i∈Nk​(X0​)∑​1(Yi​=c)

    donde 1(⋅)\mathbb{1}(\cdot)1(⋅) es la función indicadora y ccc recorre todas las clases posibles.

3.1.3 Métricas de distancia

La elección de la métrica de distancia es fundamental en KNN:

1. Distancia Euclidiana (la más común): d(Xi,Xj)=∑m=1p(Xim−Xjm)2=∥Xi−Xj∥2 d(\mathbf{X}_i, \mathbf{X}_j) = \sqrt{\sum_{m=1}^{p} (X_{im} - X_{jm})^2} = \|\mathbf{X}_i - \mathbf{X}_j\|_2 d(Xi​,Xj​)=m=1∑p​(Xim​−Xjm​)2​=∥Xi​−Xj​∥2​

2. Distancia Manhattan (city-block): d(Xi,Xj)=∑m=1p∣Xim−Xjm∣=∥Xi−Xj∥1 d(\mathbf{X}_i, \mathbf{X}_j) = \sum_{m=1}^{p} |X_{im} - X_{jm}| = \|\mathbf{X}_i - \mathbf{X}_j\|_1 d(Xi​,Xj​)=m=1∑p​∣Xim​−Xjm​∣=∥Xi​−Xj​∥1​

3. Distancia Minkowski (generalización): d(Xi,Xj)=(∑m=1p∣Xim−Xjm∣q)1/q d(\mathbf{X}_i, \mathbf{X}_j) = \left(\sum_{m=1}^{p} |X_{im} - X_{jm}|^q\right)^{1/q} d(Xi​,Xj​)=(m=1∑p​∣Xim​−Xjm​∣q)1/q

donde:

  • q=1q = 1q=1: Manhattan
  • q=2q = 2q=2: Euclidiana
  • q→∞q \to \inftyq→∞: Chebyshev

4. Distancia de Mahalanobis (considera correlaciones): d(Xi,Xj)=(Xi−Xj)⊤Σ−1(Xi−Xj) d(\mathbf{X}_i, \mathbf{X}_j) = \sqrt{(\mathbf{X}_i - \mathbf{X}_j)^\top \mathbf{\Sigma}^{-1} (\mathbf{X}_i - \mathbf{X}_j)} d(Xi​,Xj​)=(Xi​−Xj​)⊤Σ−1(Xi​−Xj​)​

3.1.4 Regla de decisión probabilística

KNN puede proporcionar probabilidades estimadas:

P(Y=c∣X0)=1k∑i∈Nk(X0)1(Yi=c) P(Y = c | \mathbf{X}_0) = \frac{1}{k} \sum_{i \in \mathcal{N}_k(\mathbf{X}_0)} \mathbb{1}(Y_i = c) P(Y=c∣X0​)=k1​i∈Nk​(X0​)∑​1(Yi​=c)

Es decir, la proporción de vecinos que pertenecen a la clase ccc.

3.1.5 Versión ponderada

En lugar de votos iguales, se pueden usar pesos inversamente proporcionales a la distancia:

Y^0=arg⁡max⁡c∑i∈Nk(X0)wi⋅1(Yi=c) \hat{Y}_0 = \arg\max_{c} \sum_{i \in \mathcal{N}_k(\mathbf{X}_0)} w_i \cdot \mathbb{1}(Y_i = c) Y^0​=argcmax​i∈Nk​(X0​)∑​wi​⋅1(Yi​=c)

donde: wi=1d(X0,Xi)+ϵ w_i = \frac{1}{d(\mathbf{X}_0, \mathbf{X}_i) + \epsilon} wi​=d(X0​,Xi​)+ϵ1​

ϵ>0\epsilon > 0ϵ>0 evita división por cero. Vecinos más cercanos tienen más influencia.

3.1.6 Parámetro k: Trade-off sesgo-varianza

k pequeño (ej: k=1):

  • Baja bias: Frontera de decisión flexible, se adapta a detalles locales
  • Alta varianza: Sensible a ruido, predicciones inestables
  • Riesgo de overfitting
  • Fronteras irregulares

k grande (ej: k=50):

  • Alta bias: Frontera de decisión suave, ignora detalles locales
  • Baja varianza: Predicciones estables
  • Riesgo de underfitting
  • Fronteras más regulares

k óptimo: Balance entre sesgo y varianza, determinado típicamente por validación cruzada.

3.1.8 Maldición de la dimensionalidad

En espacios de alta dimensión, KNN sufre severamente:

Sin estandarización, el algoritmo es inválido.

4 Árboles de decisión

4.1 Fundamento del algoritmo

Los árboles de decisión son modelos no paramétricos que segmentan recursivamente el espacio de características mediante reglas de decisión simples, creando una estructura jerárquica tipo árbol. Son altamente interpretables y capturan relaciones no lineales complejas.

4.1.1 Estructura del árbol

Un árbol de decisión consiste en:

Nodo raíz: Contiene todos los datos

Nodos internos: Representan decisiones basadas en características

  • Test en una característica: Xj≤tX_j \leq tXj​≤t
  • División binaria del espacio

Hojas (nodos terminales): Contienen predicciones

  • Clasificación: Clase mayoritaria en la hoja
  • Probabilidad: Distribución empírica de clases

Ramas: Conectan nodos, representan resultados de tests

4.1.2 Algoritmo de construcción recursiva

El algoritmo CART (Classification and Regression Trees) construye el árbol mediante particiones binarias recursivas:

Paso 1 - Selección de división óptima:

Para cada nodo, encontrar la mejor división (j,t)(j, t)(j,t) que minimiza una función de impureza:

(j∗,t∗)=arg⁡min⁡j,t[NL⋅I(L)+NR⋅I(R)] (j^*, t^*) = \arg\min_{j, t} \left[ N_L \cdot I(L) + N_R \cdot I(R) \right] (j∗,t∗)=argj,tmin​[NL​⋅I(L)+NR​⋅I(R)]

donde:

  • jjj: Índice de característica
  • ttt: Umbral de división
  • NL,NRN_L, N_RNL​,NR​: Número de muestras en nodo izquierdo/derecho
  • I(L),I(R)I(L), I(R)I(L),I(R): Impureza de nodos hijo

Paso 2 - División:

Dividir datos según Xj≤tX_j \leq tXj​≤t:

  • Izquierda: {(Xi,Yi):Xij≤t}\{(\mathbf{X}_i, Y_i) : X_{ij} \leq t\}{(Xi​,Yi​):Xij​≤t}
  • Derecha: {(Xi,Yi):Xij>t}\{(\mathbf{X}_i, Y_i) : X_{ij} > t\}{(Xi​,Yi​):Xij​>t}

Paso 3 - Recursión:

Repetir para cada nodo hijo hasta cumplir criterio de parada.

4.1.3 Criterios de impureza

1. Índice de Gini (Gini Impurity):

Gini(N)=1−∑k=1Kpk2 \text{Gini}(N) = 1 - \sum_{k=1}^{K} p_k^2 Gini(N)=1−k=1∑K​pk2​

donde pkp_kpk​ es la proporción de muestras de clase kkk en el nodo NNN.

Interpretación: Probabilidad de clasificar incorrectamente una observación aleatoria si se etiqueta aleatoriamente según distribución del nodo.

Propiedades:

  • Mínimo: 0 (nodo puro, todas las muestras de una clase)
  • Máximo: 1−1/K1 - 1/K1−1/K (distribución uniforme sobre KKK clases)
  • Para K=2K=2K=2: Máximo en p=0.5p=0.5p=0.5, Gini = 0.5

2. Entropía (Entropy):

Entropy(N)=−∑k=1Kpklog⁡2(pk) \text{Entropy}(N) = -\sum_{k=1}^{K} p_k \log_2(p_k) Entropy(N)=−k=1∑K​pk​log2​(pk​)

(por convención, 0log⁡0=00 \log 0 = 00log0=0)

Interpretación: Cantidad promedio de información (en bits) necesaria para codificar la clase.

Propiedades:

  • Mínimo: 0 (nodo puro)
  • Máximo: log⁡2(K)\log_2(K)log2​(K) (distribución uniforme)
  • Para K=2K=2K=2: Máximo en p=0.5p=0.5p=0.5, Entropy = 1

Ganancia de información (Information Gain): IG=Entropy(padre)−[NLNEntropy(L)+NRNEntropy(R)] \text{IG} = \text{Entropy}(\text{padre}) - \left[\frac{N_L}{N}\text{Entropy}(L) + \frac{N_R}{N}\text{Entropy}(R)\right] IG=Entropy(padre)−[NNL​​Entropy(L)+NNR​​Entropy(R)]

3. Error de clasificación:

Error(N)=1−max⁡kpk \text{Error}(N) = 1 - \max_k p_k Error(N)=1−kmax​pk​

Menos sensible que Gini y Entropy; menos usado en práctica.

4.1.4 Comparación Gini vs Entropy

Para clasificación binaria:

Gini=2p(1−p) \text{Gini} = 2p(1-p) Gini=2p(1−p)

Entropy=−plog⁡2(p)−(1−p)log⁡2(1−p) \text{Entropy} = -p\log_2(p) - (1-p)\log_2(1-p) Entropy=−plog2​(p)−(1−p)log2​(1−p)

Diferencias:

  • Entropy penaliza más desigualdades
  • Gini es más rápido de calcular (no requiere logaritmo)
  • En práctica, producen árboles similares

4.1.5 Criterios de parada

El proceso de división se detiene cuando:

  1. Pureza perfecta: Todas las muestras en el nodo pertenecen a la misma clase

  2. Profundidad máxima (max_depth): Se alcanza profundidad especificada

  3. Muestras mínimas para dividir (min_samples_split): Nnodo<min_samples_split N_{\text{nodo}} < \text{min\_samples\_split} Nnodo​<min_samples_split

  4. Muestras mínimas en hoja (min_samples_leaf): División resultaría en hoja con menos muestras que umbral

  5. Ganancia de información insuficiente (min_impurity_decrease): ΔImpurity<threshold \Delta \text{Impurity} < \text{threshold} ΔImpurity<threshold

  6. Número de hojas máximo (max_leaf_nodes): Se alcanza número especificado de hojas

4.1.6 Predicción

Para clasificar una nueva observación X0\mathbf{X}_0X0​:

Paso 1: Comenzar en raíz

Paso 2: Seguir ramas según tests:

  • Si X0j≤tX_{0j} \leq tX0j​≤t: ir a nodo izquierdo
  • Si X0j>tX_{0j} > tX0j​>t: ir a nodo derecho

Paso 3: Al llegar a hoja, predecir:

Clase: Y^0=arg⁡max⁡kpk(hoja) \hat{Y}_0 = \arg\max_k p_k^{(\text{hoja})} Y^0​=argkmax​pk(hoja)​

Probabilidad: P(Y=k∣X0)=pk(hoja)=Nk(hoja)N(hoja) P(Y=k|\mathbf{X}_0) = p_k^{(\text{hoja})} = \frac{N_k^{(\text{hoja})}}{N^{(\text{hoja})}} P(Y=k∣X0​)=pk(hoja)​=N(hoja)Nk(hoja)​​

4.1.7 Fronteras de decisión

Las fronteras son hiperplanos perpendiculares a los ejes (axis-aligned):

  • Cada división crea frontera perpendicular a un eje de característica
  • Partición recursiva del espacio en regiones rectangulares
  • Dentro de cada región: predicción constante

Limitación: No puede representar eficientemente fronteras oblicuas (ej: X1+X2=0X_1 + X_2 = 0X1​+X2​=0).

4.1.8 Importancia de características

La importancia de característica jjj se calcula como:

Importance(j)=∑N:usa XjΔImpurity(N)⋅Nsamples(N)Ntotal \text{Importance}(j) = \sum_{N : \text{usa } X_j} \Delta \text{Impurity}(N) \cdot \frac{N_{\text{samples}}(N)}{N_{\text{total}}} Importance(j)=N:usa Xj​∑​ΔImpurity(N)⋅Ntotal​Nsamples​(N)​

Suma ponderada de reducción de impureza sobre todos los nodos que usan XjX_jXj​.

Normalización: ∑j=1pImportance(j)=1 \sum_{j=1}^{p} \text{Importance}(j) = 1 j=1∑p​Importance(j)=1

4.1.9 Poda del árbol (Pruning)

Para controlar overfitting:

1. Pre-pruning (early stopping): Detener crecimiento usando criterios de parada estrictos

2. Post-pruning (pruning): Construir árbol completo, luego podar:

Cost-Complexity Pruning: Rα(T)=R(T)+α∣T∣ R_\alpha(T) = R(T) + \alpha |T| Rα​(T)=R(T)+α∣T∣

donde:

  • R(T)R(T)R(T): Error de clasificación del árbol
  • ∣T∣|T|∣T∣: Número de hojas
  • α≥0\alpha \geq 0α≥0: Parámetro de complejidad

Seleccionar α\alphaα que minimiza error de validación cruzada.

  2. No requiere preprocesamiento: No necesita estandarización ni normalización

  4. No paramétrico: No asume distribución de datos

  5. Captura no linealidades: Automáticamente modela interacciones complejas

  6. Robustez a outliers: En variables independientes (no en Y)

  7. Selección implícita de features: Usa solo características informativas

  8. Manejo de missing values: Algoritmos con estrategias para datos faltantes

4.1.11 Limitaciones

  1. Overfitting: Tendencia a ajustar demasiado datos de entrenamiento

    • Árboles profundos memorizan ruido

  2. Inestabilidad: Alta varianza

    • Pequeños cambios en datos → árbol completamente diferente
    • No robusto

  3. Sesgo con clases desbalanceadas: Tiende a favorecer clase mayoritaria

  4. Fronteras axis-aligned: No eficiente para fronteras oblicuas

  5. Greedy algorithm: Optimización local en cada división

    • No garantiza árbol globalmente óptimo

  6. Discontinuidades: Predicciones cambian abruptamente en fronteras

5 Random Forests

5.1 Fundamento del algoritmo

Random Forests (Bosques Aleatorios) es un método de ensemble que combina múltiples árboles de decisión para producir un clasificador más robusto y preciso. Fue propuesto por Leo Breiman en 2001 y se basa en el principio de “la sabiduría de las multitudes”.

5.1.1 Concepto central: Ensemble Learning

Idea fundamental: Combinar predicciones de múltiples modelos débiles para crear un modelo fuerte.

Analogía: Consultar a múltiples expertos y promediar sus opiniones suele dar mejor resultado que confiar en uno solo.

5.1.2 Algoritmo Random Forest

Entrada:

  • Dataset D={(Xi,Yi)}i=1n\mathcal{D} = \{(\mathbf{X}_i, Y_i)\}_{i=1}^{n}D={(Xi​,Yi​)}i=1n​
  • Número de árboles BBB
  • Número de características por división mmm

Proceso:

Para b=1,…,Bb = 1, \ldots, Bb=1,…,B:

Paso 1 - Bootstrap: Crear muestra aleatoria con reemplazo Db={muestra n observaciones de D con reemplazo} \mathcal{D}_b = \{\text{muestra } n \text{ observaciones de } \mathcal{D} \text{ con reemplazo}\} Db​={muestra n observaciones de D con reemplazo}

Aproximadamente 63.2% de observaciones únicas en cada muestra (algunas repetidas, otras excluidas).

Paso 2 - Entrenar árbol con randomización adicional:

Para cada nodo del árbol bbb:

  • Seleccionar aleatoriamente mmm características de las ppp disponibles
  • Encontrar mejor división usando solo estas mmm características
  • Dividir nodo
  • Repetir recursivamente

Paso 3 - Crecer árbol completo: Sin poda (o con poda mínima). Cada árbol tiene alta varianza pero bajo sesgo.

Predicción:

Para nueva observación X0\mathbf{X}_0X0​:

Clasificación (votación mayoritaria): Y^0=moda{Y^0(1),Y^0(2),…,Y^0(B)} \hat{Y}_0 = \text{moda}\{\hat{Y}_0^{(1)}, \hat{Y}_0^{(2)}, \ldots, \hat{Y}_0^{(B)}\} Y^0​=moda{Y^0(1)​,Y^0(2)​,…,Y^0(B)​}

Probabilidad: P^(Y=k∣X0)=1B∑b=1B1(Y^0(b)=k) \hat{P}(Y=k|\mathbf{X}_0) = \frac{1}{B} \sum_{b=1}^{B} \mathbb{1}(\hat{Y}_0^{(b)} = k) P^(Y=k∣X0​)=B1​b=1∑B​1(Y^0(b)​=k)

5.1.3 Dos fuentes de aleatoriedad

Random Forests introduce dos niveles de aleatoriedad:

1. Bootstrap (Bagging):

  • Diferentes muestras de entrenamiento para cada árbol
  • Reduce varianza al promediar predictores correlacionados

2. Random Feature Selection:

  • Diferentes subsets de características en cada división
  • Decorrelaciona los árboles
  • Típicamente m=pm = \sqrt{p}m=p​ para clasificación

Sin (2), los árboles serían muy similares (correlacionados), y el promedio no reduciría tanto la varianza.

5.1.4 Relación con Bagging

Bagging (Bootstrap Aggregating): Caso especial de Random Forest donde m=pm = pm=p

Random Forest = Bagging + Random Feature Selection

La selección aleatoria de features es la innovación clave que mejora Bagging.

5.1.5 Out-of-Bag (OOB) Error

Para cada árbol bbb, aproximadamente 37% de observaciones no están en Db\mathcal{D}_bDb​.

Estas observaciones Out-of-Bag pueden usarse como conjunto de validación interno:

OOB Error=1n∑i=1n1(Yi≠1∣Bi∣∑b∈BiY^i(b)) \text{OOB Error} = \frac{1}{n} \sum_{i=1}^{n} \mathbb{1}\left(Y_i \neq \frac{1}{|B_i|}\sum_{b \in B_i} \hat{Y}_i^{(b)}\right) OOB Error=n1​i=1∑n​1(Yi​=∣Bi​∣1​b∈Bi​∑​Y^i(b)​)

donde BiB_iBi​ es el conjunto de árboles que no usaron observación iii.

Ventaja: No requiere conjunto de validación separado.

5.1.6 Importancia de características

Random Forests calcula dos medidas de importancia:

1. Mean Decrease Impurity (MDI):

Importance(Xj)=1B∑b=1B∑N∈Tb:usa XjΔI(N)⋅nNn \text{Importance}(X_j) = \frac{1}{B} \sum_{b=1}^{B} \sum_{N \in T_b : \text{usa } X_j} \Delta I(N) \cdot \frac{n_N}{n} Importance(Xj​)=B1​b=1∑B​N∈Tb​:usa Xj​∑​ΔI(N)⋅nnN​​

Promedio sobre todos los árboles de la reducción de impureza cuando se usa XjX_jXj​.

2. Mean Decrease Accuracy (MDA) (Permutation Importance):

Para cada característica XjX_jXj​:

  1. Calcular OOB error original
  2. Permutar aleatoriamente valores de XjX_jXj​ en OOB
  3. Recalcular OOB error
  4. Importancia = Incremento en error

Importance(Xj)=OOB Errorpermutado−OOB Errororiginal \text{Importance}(X_j) = \text{OOB Error}_{\text{permutado}} - \text{OOB Error}_{\text{original}} Importance(Xj​)=OOB Errorpermutado​−OOB Errororiginal​

Interpretación: Si XjX_jXj​ es importante, permutarla aumentará significativamente el error.

5.1.7 Propiedades teóricas

Teorema (Breiman):

Bajo ciertas condiciones, cuando B→∞B \to \inftyB→∞:

lim⁡B→∞ErrorRF=ρ⋅σˉ2⋅(1−s2) \lim_{B \to \infty} \text{Error}_{RF} = \rho \cdot \bar{\sigma}^2 \cdot (1 - s^2) B→∞lim​ErrorRF​=ρ⋅σˉ2⋅(1−s2)

donde:

  • ρ\rhoρ: Correlación promedio entre árboles
  • σˉ2\bar{\sigma}^2σˉ2: Varianza promedio de cada árbol
  • sss: Fuerza promedio de cada árbol

Implicaciones:

  1. Aumentar B: Siempre ayuda (no overfitting)
  2. Reducir ρ (decorrelación): Ayuda → Random feature selection
  3. Aumentar fuerza árboles: Ayuda → Usar más características

5.1.9 Ventajas

  1. Reduce overfitting: Vs árbol único, por promediado

  2. Alta precisión: Entre los mejores algoritmos out-of-the-box

  3. Robusto: Menos sensible a hiperparámetros que otros métodos

  4. Maneja alta dimensionalidad: Funciona bien incluso con ppp grande

  5. Importancia de features: Proporciona ranking de características

  6. No requiere estandarización: Como árboles individuales

  7. Paralelizable: Árboles se entrenan independientemente

  8. OOB error: Validación interna sin conjunto separado

  9. Maneja missing values: Estrategias incorporadas

  10. Versátil: Funciona bien en diversos problemas

5.1.10 Limitaciones

  1. Menos interpretable: Difícil entender modelo (caja negra)

  2. Costo computacional:

    • Entrenamiento: O(B⋅nlog⁡n⋅m)O(B \cdot n \log n \cdot m)O(B⋅nlogn⋅m)
    • Predicción: O(B⋅log⁡n)O(B \cdot \log n)O(B⋅logn) Más lento que un árbol único

  3. Memoria: Requiere almacenar BBB árboles

  4. Extrapolación limitada: No predice fuera del rango de datos de entrenamiento

  5. Sesgo con clases desbalanceadas: Puede favorecer clase mayoritaria

  6. No captura tendencias lineales simples: A veces un modelo simple es mejor

  2. max_features:

    • Regresión: p/3p/3p/3
    • Probar también log⁡2(p)\log_2(p)log2​(p) y p/2p/2p/2

  • min_samples_split: [2, 5, 10]

def calcular_roc_multimodelo(modelos_dict, X_test, y_test):
    """Calcula curvas ROC para múltiples modelos"""
    
    plt.figure(figsize=(10, 8))
    
    for nombre, modelo in modelos_dict.items():
        # Obtener probabilidades
        if hasattr(modelo, 'predict_proba'):
            probs = modelo.predict_proba(X_test)[:, 1]
        else:
            probs = modelo.decision_function(X_test)
        
        # Calcular curva ROC
        fpr, tpr, _ = roc_curve(y_test, probs)
        roc_auc = auc(fpr, tpr)
        
        # Graficar
        plt.plot(fpr, tpr, linewidth=2, 
                label=f'{nombre} (AUC={roc_auc:.3f})')
    
    # Línea diagonal
    plt.plot([0, 1], [0, 1], 'k--', linewidth=2, label='Azar (AUC=0.5)')

10 Conclusión

En esta guía hemos explorado los principales algoritmos de clasificación:

Regresión Logística

Modelo lineal simple y rápido. Usa función sigmoide para probabilidades. Interpretable. Bueno como baseline.

K-Nearest Neighbors (KNN)

No paramétrico. Clasifica según vecinos más cercanos. Sensible a escala. Bueno para fronteras complejas.

Árboles de Decisión

Reglas interpretables. No requiere normalización. Propenso a overfitting. Base para métodos ensemble.

Random Forests

Ensemble de árboles. Reduce overfitting. Alta precisión. Menos interpretable que árbol único.

Comparación de modelos

Importancia de evaluar múltiples algoritmos. Usar validación cruzada. Considerar trade-offs interpretabilidad vs precisión.
